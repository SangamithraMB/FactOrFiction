# Fact or Fiction

## 🏆 Hackathon Project –  [September 2024]

Team Size: 7 | Duration: 3 Days
🛠 Tech Stack: Python

### 📌 Overview

WikiLib Fact or Fiction is an interactive fact-checking game that challenges players to determine whether a statement is real or made up. Built during a 72-hour hackathon, the game uses Wikipedia data to generate both factual and fictional statements, testing users’ knowledge and critical thinking.

### 🚀 Features

* Fetches real-time Wikipedia content to generate statements
* Randomly creates fictional statements based on extracted data
* Validates player responses and provides real-time feedback
* Scores players based on accuracy and response time
* Simple command-line interface for quick gameplay

### 🔧 **How It Works**
1. 	The game pulls content from Wikipedia and extracts key facts.
2. 	Some statements are altered to create false information.
3. 	The player must decide if the statement is Fact or Fiction.
4. 	The game evaluates the response and updates the score.

### 📂 Installation & Setup
1. Clone the repository:
    `git clone git@github.com:SangamithraMB/FactOrFiction.git
    cd wikilib-fact-or-fiction`
2. Install dependencies:
`pip install -r requirements.txt`
3. Run the game:
`python main.py`
